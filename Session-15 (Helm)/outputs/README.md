# Helm command outputs

This directory is reserved for terminal-output records corresponding to the command practice, rollback workflow, and cleanup evidence in the parent README.

| Suggested file | Contents |
|---|---|
| `01-commands-repo.txt` | Chart creation, repository, and search commands |
| `02-install-status.txt` | Lint, template, install, list, and status |
| `03-get.txt` | Release values, manifests, notes, and metadata |
| `04-upgrade.txt` | Production upgrade verification |
| `05-rollback.txt` | Failed revision, history, rollback, and restored release |
| `06-uninstall.txt` | Uninstall and release-list verification |
